Objetivos de Aprendizagem
Estruturas de Dados: Compreender a manipulação de listas, dicionários, tuplas e conjuntos no ecossistema analítico.

Manipulação e Engenharia de Dados: Carregar, tratar, limpar e transformar massas tabulares com NumPy e Pandas.

Modelagem e Machine Learning: Estruturar pipelines de pré-processamento, dividir conjuntos de treino/teste sem vazamento de dados (data leakage) e avaliar classificadores/regressores com Scikit-Learn.

Boas Práticas de Engenharia: Utilizar ambientes virtuais (.venv), gerenciar dependências via requirements.txt e organizar códigos prontos para inferência.
